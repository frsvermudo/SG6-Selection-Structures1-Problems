# Python Programming Problems

## Description
This repository contains three Python programs that solve basic programming problems using conditional statements and Boolean logic.

## How to Run
1. Open the program file in VS Code, Programiz, Replit, or Google Colab.
2. Run the program.
3. Enter the required values.
4. Check the result displayed on the screen.

## Problem 1 - Odd or Even
### Description
This program determines whether a given integer is odd or even.

### Pseudocode
START

Input number

IF number divided by 2 has a remainder of 0 THEN

* Display "Even"

ELSE

* Display "Odd"

END IF

END

### Sample Output
Enter a number: 27
Odd

## Problem 2 - Grade Evaluation
### Description
This program determines a student's letter grade based on their score.

### Pseudocode
START

Input score

IF score is 90 or higher THEN

* Display "A"

ELSE IF score is 80 or higher THEN

* Display "B"

ELSE IF score is 70 or higher THEN

* Display "C"

ELSE

* Display "D"

END IF

END

### Sample Output
Enter your score: 86
Grade: B

## Problem 3 - Discount Eligibility Checker
### Description
This program determines whether a person is eligible for a discount based on their student status, age, and membership.

### Pseudocode
START

Input student status

Input age

Input membership status

IF (student = "Y" OR age ≥ 65) AND (membership = "yes") THEN

* Display "You are eligible for a discount."

ELSE

* Display "You are not eligible for a discount."

END IF

END

### Sample Output

Do you have a membership card? yes
You are eligible for a discount.
